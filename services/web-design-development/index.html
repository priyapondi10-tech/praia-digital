Service guide

Web Design & Development

Turn a confusing or outdated website into a clear set of pages that visitors can understand and a team can maintain.

What this service covers

A website project starts with the people who will use it. The proposed work brings audience needs, page structure, content, and responsive implementation into one brief. It suits a new service website or a focused rebuild where the current navigation makes important information hard to find.

  • A page inventory and a proposed navigation structure.
  • Responsive page layouts with meaningful headings and descriptive links.
  • Implementation of agreed pages and reusable visual styles.
  • A launch checklist and practical editing instructions.

How the work is organised

  1. Review the existing site, audience, and priority visitor journeys.
  2. Agree the page map, content responsibilities, and design direction.
  3. Build the agreed pages and review them on narrow and wide screens.
  4. Check navigation and content, then document the handover.

Hosting, domain access, third-party integrations, and migration work need explicit agreement. A static website does not include a working enquiry backend unless one is separately implemented and tested.

Prepare your brief

Gather your current website address, brand assets, draft copy, required pages, and examples of problems visitors report. Name a person who can approve content and describe the action each important page should support.

After launch, use Website Care to plan regular checks and keep information current.
